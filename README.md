# Healthcare Login Screen - Flutter

A modern, clean login screen for a healthcare mobile app built with Flutter, inspired by contemporary healthcare app designs.

## Features

- **Modern UI Design**: Clean, professional interface with healthcare-focused styling
- **Form Validation**: Email and password validation with user-friendly error messages
- **Interactive Elements**: 
  - Password visibility toggle
  - Remember me checkbox
  - Forgot password link
- **Social Login**: Apple and Google sign-in options
- **Responsive Design**: Optimized for mobile devices
- **Accessibility**: Proper contrast ratios and touch targets

## Design Elements

- **Color Scheme**: Professional blue (#3B82F6) with clean grays and whites
- **Typography**: Clean, readable fonts with proper hierarchy
- **Icons**: Medical services icon and intuitive form icons
- **Spacing**: Consistent padding and margins for better UX
- **Shadows & Borders**: Subtle elevation and rounded corners

## Getting Started

1. **Prerequisites**: Make sure you have Flutter installed on your system
2. **Installation**: 
   ```bash
   flutter pub get
   ```
3. **Run the app**:
   ```bash
   flutter run
   ```
